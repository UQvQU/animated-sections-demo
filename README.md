# Animated Sections

A five-section scrolling animation demo built with HTML, CSS, JavaScript, and GSAP.

## Preview

Open `index.html` and scroll up or down to navigate the looping sections.

The five background images are included in `images/`. GSAP 3.13.0 and its Observer and SplitText plugins load from jsDelivr.

## GitHub Pages

Publish from the `main` branch and root folder in Settings > Pages.
